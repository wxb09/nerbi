## 🔍 页面功能分析 & 接口需求

### 1. 登录页 (`login.html`)

| 功能 | 方法 | 接口 | 请求体 | 响应 |
|------|------|------|--------|------|
| 手机号+验证码登录 | `POST` | `/api/auth/login/phone` | `{phone, verifyCode}` | `{token, user}` |
| 发送验证码 | `POST` | `/api/auth/verify-code` | `{phone}` | `{success, message}` |
| 人脸识别认证 | `POST` | `/api/auth/login/face` | `{faceData}` | `{token, user}` |
| 微信/支付宝/Apple登录 | `POST` | `/api/auth/login/{provider}` | `{authCode}` | `{token, user}` |
| 游客模式 | `GET` | `/api/auth/guest` | - | `{tempToken}` |

| 获取分类列表 | `GET` | `/api/categories` | - | `[{id, name, icon}]` |
| 获取碳排放统计 | `GET` | `/api/stats/carbon` | `?community=栖霞苑` | `{weeklySaved, totalSaved}` |

### 5. 发布闲置页 (`publish.html`)

| 功能 | 方法 | 接口 | 请求体 | 响应 |
|------|------|------|--------|------|
| 上传图片 | `POST` | `/api/upload/images` | `FormData: files[]` | `[{url, id}]` |
| 创建物品 | `POST` | `/api/items` | `{name, categoryId, description, images[], rules: {price, deposit, creditRequired}, tags[], location}` | `{itemId}` |
| 更新物品(草稿) | `PUT` | `/api/items/{id}` | 同上 | `{itemId}` |
| 获取分类选项 | `GET` | `/api/categories` | - | `[{id, name}]` |
| 保存草稿 | `POST` | `/api/items/draft` | 同创建 | `{draftId}` |

**发布流程状态机：**
```
草稿 -> 已发布 -> 审核中 -> 已上架
        ↓
      已下架/已删除
```

## 📋 完整 API 清单汇总

### 认证模块 (`/api/auth`)
```
POST /api/auth/login/phone      # 手机号登录
POST /api/auth/login/face       # 人脸登录
POST /api/auth/login/{provider} # 第三方登录
POST /api/auth/verify-code      # 发送验证码
POST /api/auth/logout           # 退出登录
GET  /api/auth/guest            # 游客模式
```

### 用户模块 (`/api/users`)
```
GET    /api/users/me            # 当前用户信息
PUT    /api/users/me            # 更新用户信息
GET    /api/users/{id}/profile  # 查看他人资料
GET    /api/users/me/items      # 我的发布
GET    /api/users/me/lent       # 我借出的
GET    /api/users/me/borrowed   # 我借入的
GET    /api/users/me/pending    # 待处理申请
GET    /api/users/me/reviews    # 我的评价
```

### 物品模块 (`/api/items`)
```
GET    /api/items               # 物品列表
GET    /api/items/search        # 搜索
GET    /api/items/filter        # 筛选
POST   /api/items               # 创建物品
GET    /api/items/{id}          # 物品详情
PUT    /api/items/{id}          # 更新物品
DELETE /api/items/{id}          # 删除物品
PUT    /api/items/{id}/withdraw # 撤回发布
GET    /api/items/{id}/images   # 物品图片
GET    /api/items/{id}/similar  # 相似推荐
POST   /api/items/draft         # 保存草稿
```

### 借阅模块 (`/api/borrows`)
```
POST   /api/borrows             # 提交借阅申请
GET    /api/borrows/{id}        # 借阅详情
POST   /api/borrows/{id}/approve # 审批申请
POST   /api/borrows/{id}/remind  # 提醒归还
POST   /api/borrows/{id}/return  # 确认归还/收回
PUT    /api/borrows/{id}/extend  # 延期申请
```

### 社区模块 (`/api/posts`, `/api/communities`)
```
GET    /api/posts               # 帖子列表
POST   /api/posts               # 发布帖子
POST   /api/posts/{id}/like     # 点赞
POST   /api/posts/{id}/comments # 评论
GET    /api/announcements       # 社区公告
GET    /api/leaderboard/green   # 绿色榜单
GET    /api/skills/exchange     # 技能交换
```

### 通用模块
```
GET    /api/communities         # 社区列表
GET    /api/categories          # 分类列表
POST   /api/upload/images       # 图片上传
POST   /api/messages            # 发送消息/联系
GET    /api/stats/carbon        # 碳排放统计
```

## 📊 数据模型关键字段

### Item (物品)
```javascript
{
  id: String,
  name: String,
  category: { id, name, icon },
  description: String,
  story: String,           // 背后的故事
  images: [{ url, isMain }],
  owner: { id, name, avatar, credit, location },
  rules: {
    pricePerDay: Number,   // 0表示免费
    deposit: Number,
    creditRequired: Number,
    returnRequirements: [String] // ["已消毒", "保持原样"]
  },
  status: "available|borrowed|offline|pending",
  location: { community, building, detail },
  stats: { borrowCount, viewCount, favoriteCount },
  tags: [String],
  createdAt: Date
}
```

### Borrow (借阅记录)
```javascript
{
  id: String,
  item: { id, name, image },
  lender: { id, name },    // 借出方
  borrower: { id, name },  // 借入方
  dates: {
    start: Date,
    end: Date,
    actualReturn: Date
  },
  purpose: String,         // 用途简述
  status: "pending|approved|active|returned|overdue|cancelled",
  messages: [{ from, content, time }],
  createdAt: Date
}
```

### User (用户)
```javascript
{
  id: String,
  phone: String,
  profile: {
    nickname: String,
    avatar: String,
    bio: String,
    location: { community, building, unit }
  },
  credit: {
    score: Number,          // 0-10
    level: "excellent|good|normal",
    borrowCount: Number,
    lendCount: Number
  },
  eco: {
    co2Saved: Number,       // 克
    medalProgress: Number   // 0-100
  },
  settings: {
    notifications: Boolean,
    privacy: Object
  }
}
```
