# 邻里共享项目分析与下一步（Spring Boot 3 + Vue 3）

## 1. 目标与范围

- 目标：基于原型 HTML 页面，完成页面、跳转、功能与后端能力的梳理，并形成可开工的接口契约。
- 技术栈：`Spring Boot 3` + `Vue 3`
- 当前约定：登录成功默认跳转 ` /index `
- 本文档阶段：仅需求与设计，不涉及代码实现。

---

## 2. 原型页面清单

当前共 6 个核心页面：

- `login.html`：认证入口（手机号验证码 / 人脸 / 三方 / 游客）
- `index.html`：首页发现流（搜索、筛选、推荐列表）
- `detail.html`：物品详情 + 借阅申请
- `forum.html`：社区论坛（发帖、点赞、评论、公告、榜单）
- `publish.html`：发布闲置（上传图、基础信息、规则设置、发布/草稿）
- `profile.html`：个人中心（借出借入管理、统计、评价、退出登录）

---

## 3. 页面跳转关系（按原型实际链接）

### 3.1 主导航

- `index` -> `forum` / `publish` / `profile`
- `index` -> `detail`（查看详情）
- `detail` -> `index`（返回探索）/ `profile`
- `forum` -> `index` / `publish` / `profile`
- `publish` -> `index`（logo）/ `profile`（取消并返回）
- `login` -> `index`（先去随便看看）/ `profile`（验证并进入社区）

### 3.2 认证相关

- `index` 顶部“退出” -> `login`
- 业务约定：登录成功后默认进入 ` /index `

## 6. 业务状态机（统一枚举）

## 6.1 物品状态 `ItemStatus`

- `DRAFT`：草稿
- `PUBLISHED`：已发布待审（可选）
- `AVAILABLE`：可借
- `BORROWED`：借出中
- `OFFLINE`：下架
- `DELETED`：删除

关键流转：

- 发布：`DRAFT -> AVAILABLE`
- 借出：`AVAILABLE -> BORROWED`
- 归还：`BORROWED -> AVAILABLE`
- 下架：`AVAILABLE/BORROWED -> OFFLINE`

## 6.2 借阅状态 `BorrowStatus`

- `PENDING`：待审批
- `APPROVED`：已同意
- `ACTIVE`：借用中
- `RETURNED`：已归还
- `OVERDUE`：超期
- `REJECTED`：已拒绝
- `CANCELLED`：已取消

关键流转：

- 发起申请：`PENDING`
- 同意：`PENDING -> APPROVED -> ACTIVE`
- 拒绝：`PENDING -> REJECTED`
- 正常归还：`ACTIVE -> RETURNED`
- 超期后归还：`ACTIVE -> OVERDUE -> RETURNED`

## 7. 接口契约 V1（字段级）

## 7.1 统一约定

- Base URL：`/api`
- 鉴权：`Authorization: Bearer <JWT>`
- 时间格式：ISO 8601
- 分页请求参数：`page`（从 1 开始）、`size`
- 统一响应包：
  - 成功：`{ "code": 0, "message": "OK", "data": {...} }`
  - 失败：`{ "code": 业务码, "message": "...", "data": null }`

分页响应：

```json
{
  "list": [],
  "total": 0,
  "page": 1,
  "size": 20,
  "hasMore": false
}
```

## 8. 错误码最小集（V1）

- `0`：成功
- `1001`：未登录 / Token 无效
- `1002`：无权限
- `2001`：参数校验失败
- `3001`：物品不存在
- `3002`：物品状态不可借（非 `AVAILABLE`）
- `3003`：信用分不足
- `4001`：借阅记录不存在
- `4002`：借阅状态不允许当前操作
- `5000`：系统异常
