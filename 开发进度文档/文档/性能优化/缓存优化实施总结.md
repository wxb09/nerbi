### Phase 1: API请求缓存层 ✅

**缓存策略**：
- GET `/categories` → 30分钟
- GET `/communities` → 30分钟
- GET `/items` → 2分钟
- GET `/forum/posts` → 2分钟
- GET `/items/{id}` → 5分钟
- GET `/forum/posts/{id}` → 5分钟

**自动失效机制**：
- POST/PUT/DELETE `/items*` → 自动清除 `/items` 相关缓存
- POST/PUT/DELETE `/forum/posts*` → 自动清除 `/forum/posts` 相关缓存
- POST/PUT/DELETE `/forum/comments*` → 自动清除评论缓存

### Phase 3: usePagination缓存增强 ✅

**ForumView.vue 已启用**：
```typescript
const { loading, data: posts, hasMore, loadMore, refresh, clearCache } = usePagination<PostList>(
  (page, size, p) => forumApi.getPosts({ ...p, page, size }),
  { 
    pageSize: 10, 
    mode: 'append', 
    params, 
    cacheKey: 'forum_posts',      // 启用缓存
    cacheTTL: 2 * 60 * 1000       // 2分钟有效期
  }
)

// 发布帖子后清除缓存
const publishPost = async () => {
  await forumApi.createPost({...})
  clearCache()  // 清除帖子列表缓存
  reloadPosts() // 重新加载
}
```
