### 缓存配置详情

```java
@Bean
public CacheManager cacheManager() {
    CaffeineCacheManager cacheManager = new CaffeineCacheManager();
    cacheManager.setCaffeine(Caffeine.newBuilder()
        .maximumSize(1000)                    // 最大缓存条目数
        .expireAfterWrite(Duration.ofMinutes(10)));  // 10分钟过期
    return cacheManager;
}
```

### 各模块缓存策略

#### 1. 帖子模块 (PostService)

| 方法            | 缓存注解                                             | 缓存Key                             | 说明        |
| :------------ | :----------------------------------------------- | :-------------------------------- | :-------- |
| `getPosts`    | `@Cacheable("posts")`                            | `communityId-type-sort-page-size` | 帖子列表缓存    |
| `getHotPosts` | `@Cacheable("hotPosts")`                         | `communityId-postType-page-size`  | 热门帖子缓存    |
| `getPostById` | `@Cacheable("postDetail")`                       | `id-currentUserId`                | 帖子详情缓存    |
| `createPost`  | `@CacheEvict("posts", "hotPosts")`               | allEntries=true                   | 创建后清除列表缓存 |
| `updatePost`  | `@CacheEvict("posts", "hotPosts", "postDetail")` | allEntries=true                   | 更新后清除所有缓存 |
| `deletePost`  | `@CacheEvict("posts", "hotPosts", "postDetail")` | allEntries=true                   | 删除后清除所有缓存 |

#### 2. 评论模块 (CommentService)

| 方法                    | 缓存注解                                    | 说明             |
| :-------------------- | :-------------------------------------- | :------------- |
| `getCommentsByPostId` | `@Cacheable("comments")`                | 评论列表缓存         |
| `createComment`       | `@CacheEvict("comments", "postDetail")` | 创建后清除评论和帖子详情缓存 |
| `deleteComment`       | `@CacheEvict("comments", "postDetail")` | 删除后清除评论和帖子详情缓存 |

#### 3. 公告模块 (AnnouncementService)

| 方法                       | 缓存注解                               | 说明           |
| :----------------------- | :--------------------------------- | :----------- |
| `getActiveAnnouncements` | `@Cacheable("announcements")`      | 公告列表缓存       |
| `getAnnouncementById`    | `@Cacheable("announcementDetail")` | 公告详情缓存       |
| `create/update/delete`   | `@CacheEvict`                      | 写操作后清除所有公告缓存 |

#### 4. 公共数据 (PublicController)

| 方法               | 缓存注解                        | 说明     |
| :--------------- | :-------------------------- | :----- |
| `getCommunities` | `@Cacheable("communities")` | 社区列表缓存 |
