## 管理员功能需求分析与优先级

### 一、当前已有功能

| 功能模块  | 状态    | 说明            |
| :---- | :---- | :------------ |
| 数据仪表盘 | ✅ 已实现 | 用户数、物品数、借阅统计等 |
| 物品审核  | ✅ 已实现 | 审核物品发布申请      |
| 借阅纠纷  | ✅ 已实现 | 创建和处理借阅纠纷     |
| 认证审核  | ✅ 已实现 | 地址认证审核        |
| 用户管理  | ✅ 已实现 | 用户列表、封禁/解封    |

***

### 二、待开发功能分析

#### 1. **支付/押金管理** ⭐⭐⭐⭐⭐ (最高优先级)

**需求描述：**

- 查看所有支付记录（租金、押金）
- 查看押金状态（待支付、已支付、已退还）
- 处理押金纠纷（物品损坏扣款等）
- 支付统计（总交易额、待退还押金等）

**实现内容：**

- 后端：新增 `AdminPaymentController`，扩展现有 `PaymentService`
- 前端：新增 `AdminPayments.vue` 组件
- 功能：支付记录列表、筛选、详情查看、退款操作

**优先级理由：**

- 支付模块刚开发完成，趁热打铁完善管理功能
- 涉及资金安全，需要管理员监控
- 押金纠纷处理是核心业务流程

***

#### 2. **社区公告管理** ⭐⭐⭐⭐ (高优先级)

**需求描述：**

- 发布/编辑/删除社区公告
- 设置公告类型（普通/重要）
- 公告状态管理（草稿/发布/下架）
- 按社区筛选公告

**实现内容：**

- 后端：新增 `AnnouncementService`、`AnnouncementController`
- 前端：新增 `AdminAnnouncements.vue` 组件
- 数据库：已有 `announcements` 表，无需新建

**优先级理由：**

- 数据库表已存在，开发成本低
- 社区公告是运营核心功能
- 用户端已有公告展示入口

***

#### 3. **社区信息管理** ⭐⭐⭐⭐ (高优先级)

**需求描述：**

- 社区列表展示
- 新增/编辑/删除社区
- 社区统计（用户数、物品数、活跃度）
- 社区地址管理

**实现内容：**

- 后端：新增 `CommunityService`、`CommunityController`
- 前端：新增 `AdminCommunities.vue` 组件
- 数据库：已有 `communities` 表，无需新建

**优先级理由：**

- 社区是平台基础数据
- 用户注册需要选择社区
- 数据库表已存在，开发成本低

***

#### 4. **敏感词管理** ⭐⭐⭐ (中优先级)

**需求描述：**

- 敏感词列表（增删改查）
- 敏感词分类（政治、广告、辱骂等）
- 替换策略（直接拒绝/替换为\*\*\*）
- 内容过滤日志

**实现内容：**

- 后端：新增 `SensitiveWord` 实体、`SensitiveWordService`、`SensitiveWordController`
- 前端：新增 `AdminSensitiveWords.vue` 组件
- 数据库：需新建 `sensitive_words` 表
- 集成：在发帖、评论、物品描述等处添加过滤逻辑

**优先级理由：**

- 内容安全合规需求
- 需要新建表和过滤逻辑，工作量较大
- 可后期迭代优化

***

#### 5. **首页轮播图/Banner管理** ⭐⭐⭐ (中优先级)

**需求描述：**

- 轮播图上传/排序/删除
- 设置跳转链接
- 启用/禁用状态
- 按社区展示不同Banner

**实现内容：**

- 后端：新增 `Banner` 实体、`BannerService`、`BannerController`
- 前端：新增 `AdminBanners.vue` 组件
- 数据库：需新建 `banners` 表
- 文件上传：集成现有文件上传服务

**优先级理由：**

- 运营推广需要
- 需要新建表和文件上传逻辑
- 非核心业务，可延后

***

#### 6. **其他建议功能** ⭐⭐ (低优先级)

| 功能     | 说明                | 优先级理由          |
| :----- | :---------------- | :------------- |
| 系统配置管理 | 平台名称、联系方式、公告等全局配置 | 可先用配置文件，后期再界面化 |
| 操作日志   | 管理员操作记录审计         | 安全合规，但非紧急      |
| 数据导出   | 用户/物品/交易数据导出Excel | 运营需要，但可手动查询数据库 |
| 消息推送   | 系统消息群发            | 营销功能，非核心       |
