## 物品状态流转

```
DRAFT → AVAILABLE → BORROWED → AVAILABLE
           ↓
        OFFLINE → AVAILABLE
```

| 状态 | 说明 |
|-----|------|
| DRAFT | 草稿 |
| AVAILABLE | 可借 |
| BORROWED | 借出中 |
| OFFLINE | 已下架 |

---

## 借阅状态流转

```
PENDING → APPROVED → ACTIVE → RETURN_REQUESTED → RETURNED
    ↓
REJECTED
```

| 状态 | 说明 |
|-----|------|
| PENDING | 待审批 |
| APPROVED | 已同意 |
| ACTIVE | 借用中 |
| RETURN_REQUESTED | 申请归还 |
| RETURNED | 已归还 |
| REJECTED | 已拒绝 |

## 已知问题与解决方案

| 问题 | 解决方案 |
|-----|---------|
| 图片重复添加 | `Item.java` 添加 `orphanRemoval = true` |
| 上架功能失效 | 后端处理 `status` 字段 |
| 草稿编辑模式判断 | 基于物品实际状态，非 URL 参数 |
| BORROWED 禁止编辑 | 前后端双重校验 |
