## 物品状态流转

```
DRAFT → AVAILABLE → BORROWED → AVAILABLE
           ↓
        OFFLINE → AVAILABLE
```

| 状态        | 说明  |
| --------- | --- |
| DRAFT     | 草稿  |
| AVAILABLE | 可借  |
| BORROWED  | 借出中 |
| OFFLINE   | 已下架 |

***

## 借阅状态流转

```
PENDING → APPROVED → ACTIVE → RETURN_REQUESTED → RETURNED
    ↓
REJECTED
```

| 状态                | 说明   |
| ----------------- | ---- |
| PENDING           | 待审批  |
| APPROVED          | 已同意  |
| ACTIVE            | 借用中  |
| RETURN\_REQUESTED | 申请归还 |
| RETURNED          | 已归还  |
| REJECTED          | 已拒绝  |

## WebSocket 实时推送

### 连接地址

```
ws://localhost:8080/ws/message?token={jwt}
```

### 事件-推送矩阵

| 业务事件 | 推送给谁 | 推送类型 |
|---------|---------|---------|
| 借阅申请 | 物品所有者 | `NEW_BORROW_APPLY` |
| 审批通过 | 借用者 | `REQUEST_APPROVED` |
| 审批通过 | 物品所有者 | `ITEM_STATUS_CHANGED` |
| 审批拒绝 | 借用者 | `REQUEST_REJECTED` |
| 归还申请 | 物品所有者 | `RETURN_REQUESTED` |
| 确认归还 | 借用者 | `BORROW_RETURNED` |
| 确认归还 | 物品所有者 | `RETURN_CONFIRMED` |

### 定时任务

- **执行时间**：每天早上 9 点
- **到期提醒**：提前 1 天提醒借入者
- **超期提醒**：隔天提醒（同时更新状态为 `OVERDUE`）

### 前端使用

```typescript
import { wsManager } from '../utils/websocket'

// 登录后自动连接，退出后自动断开
// 监听消息
wsManager.on('NEW_BORROW_APPLY', (message) => {
  // 处理消息
})
```
