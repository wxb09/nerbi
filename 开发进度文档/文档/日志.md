## ✅ 日志级别调整

### WebSocketMessageHandler

| 日志 | 级别 |
|-----|------|
| 用户上线/下线 | `info` ✅ 保留 |
| 尝试推送消息 | `debug` |
| 用户不在线（无session） | `debug` |
| 用户不在线（session已关闭） | `info` ✅ 保留 |
| 消息推送成功 | `info` ✅ 保留 |
| 推送内容 | `debug` |
| 消息推送失败 | `error` ✅ 保留 |

### BorrowService

| 日志 | 级别 |
|-----|------|
| 创建借阅申请 | `info` ✅ 保留 |
| 借阅申请已保存 | `info` ✅ 保留 |
| 准备推送通知给借出者 | `debug` |
| 借阅申请创建完成 | `debug` |
| 审批借阅申请 | `info` ✅ 保留 |
| 审批通过/拒绝 | `info` ✅ 保留 |
| 推送给借入者/借出者 | `debug` |
| 审批完成 | `debug` |

现在生产环境默认只显示重要的日志，需要排查问题时可以开启 debug 级别。
