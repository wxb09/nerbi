## 三、分页组件封装 ✅

### 设计思路

| 层级 | 文件 | 职责 |
|-----|------|------|
| 逻辑层 | `usePagination.ts` | 数据获取、状态管理 |
| 视图层 | `Pagination.vue` | UI渲染、用户交互 |

### 使用示例

```typescript
// 逻辑层
const { data, loading, hasMore, loadMore, refresh } = usePagination(
  (page, size) => api.getPosts({ page, size }),
  { pageSize: 10, mode: 'append' }
)

// 视图层
<Pagination :page="page" :total-pages="totalPages" @change="goToPage" />
```
