## 🚨 发现的问题

### 问题1：Jackson 序列化错误（第一次申请）
```
InvalidDefinitionException: Java 8 date/time type `java.time.LocalDateTime` not supported by default
```
**原因**：`MessageDTO` 中的 `createdAt` 字段（`LocalDateTime` 类型）无法被 Jackson 序列化为 JSON。

### 问题2：WebSocket 推送失败
两次申请都显示：
```
[WebSocket] 用户不在线，无法推送：userId=1
```

## 🔧 解决方案

### 1. 修复 Jackson 序列化问题

在你的 `WebSocketMessageHandler` 或配置中，确保 ObjectMapper 注册了 Java 8 时间模块：

```java
// 方式1：在 WebSocketMessageHandler 中配置
private final ObjectMapper objectMapper = new ObjectMapper()
    .registerModule(new JavaTimeModule())
    .disable(SerializationFeature.WRITE_DATES_AS_TIMESTAMPS);

// 方式2：或者使用 Spring 的 ObjectMapper（推荐）
@Autowired
private ObjectMapper objectMapper;  // Spring Boot 会自动配置好
```

检查你的 `pom.xml`，确保有：
```xml
<dependency>
    <groupId>com.fasterxml.jackson.datatype</groupId>
    <artifactId>jackson-datatype-jsr310</artifactId>
</dependency>
```

### 2. 检查 WebSocket 连接状态

日志显示用户1（借出者）**不在线**，但日志前面显示：

```
2026-04-06T17:59:40.920+08:00  INFO ... : 用户上线：userId=1, sessionId=abe9abca-6757-9dfe-a010-7251f492fdf3, 当前在线人数=1
```

用户1确实连接过，但后续推送时显示不在线。可能原因：
- 用户1的 WebSocket 连接已断开
- 用户1没有保持心跳（但日志显示有 PING 消息）

检查 `WebSocketMessageHandler` 中的用户会话管理逻辑，确认 `userSessions` Map 是否正确维护了用户会话。
