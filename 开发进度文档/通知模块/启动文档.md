### 三、定时任务技术选型

#### 方案对比

| 方案                          | 优点                         | 缺点          |  推荐度  |
| --------------------------- | -------------------------- | ----------- | :---: |
| **Spring** **`@Scheduled`** | 无需额外依赖、简单易用、Spring Boot 内置 | 单机模式、无持久化   | ⭐⭐⭐⭐⭐ |
| Quartz                      | 功能强大、支持集群、持久化              | 需要额外依赖、配置复杂 |  ⭐⭐⭐  |
| XXL-JOB                     | 分布式任务调度、可视化                | 需要额外部署、重量级  |   ⭐⭐  |

**推荐方案**：**Spring** **`@Scheduled`**

理由：

1. 项目规模不大，单机部署足够
2. 无需引入额外依赖（pom.xml 目前没有 Quartz）
3. Spring Boot 3.3.5 原生支持，开箱即用
4. 提醒任务逻辑简单，不需要复杂的调度策略
