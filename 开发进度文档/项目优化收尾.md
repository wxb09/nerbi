## 邻里共享平台 - 项目整体认知报告

### 一、项目定位与核心价值

**邻里共享平台**是一个面向社区居民的**物品共享与社区互动系统**，旨在通过数字化手段促进社区内的资源共享、循环利用和邻里交流。项目已完成 **92%** 的开发进度（截至2026-04-23），核心功能全部实现，正处于**收尾优化阶段**。

---

### 二、技术架构总览

| 层级 | 技术选型 | 说明 |
|------|---------|------|
| **前端** | Vue 3 + TypeScript + Vite + TailwindCSS + Pinia | 单页应用，Composition API |
| **后端** | Spring Boot 3.3.5 + JPA + MySQL 8 + Flyway | RESTful API，数据库版本管理 |
| **认证** | JWT (jjwt 0.12.6) | 无状态身份验证 |
| **实时通信** | WebSocket | 消息推送、实时通知 |
| **支付** | 支付宝沙箱 | 租金与押金在线支付 |
| **图片存储** | 本地文件系统 | 上传目录：`backend/demo/uploads/` |

### 三、核心业务模块

#### 1. 用户认证模块 ✅
- **功能**：手机号验证码登录（测试码：123456）、密码登录、JWT Token管理
- **特色**：自动注册新用户，登录后建立WebSocket连接
- **文件**：`AuthController.java`、`AuthService.java`、`JwtAuthenticationFilter.java`

#### 2. 物品管理模块 ✅
- **功能**：发布、编辑、上下架、图片上传、草稿保存、搜索筛选
- **状态流转**：`DRAFT → PENDING_REVIEW → AVAILABLE → BORROWED → AVAILABLE/OFFLINE`
- **特色**：支持多图上传、标签系统、归还要求配置

#### 3. 借阅管理模块 ✅
- **功能**：申请、审批、确认取货、申请归还、确认归还、提醒归还
- **状态流转**：`PENDING → APPROVED → ACTIVE → RETURN_REQUESTED → RETURNED`
- **并发控制**：使用乐观锁（`version`字段）+ 原子更新防止重复借阅

#### 4. 支付模块 ✅
- **功能**：支付宝沙箱支付、押金退还、异步通知处理
- **状态流转**：`PENDING → PAID → REFUNDED`
- **特色**：租金按天计算，归还后退还押金

#### 5. 论坛模块 ✅
- **功能**：发帖（4种类型：日常/感谢/求助/技能交换）、评论、点赞、举报
- **特色**：帖子卡片支持删除/举报操作，管理员可处理举报

#### 6. 消息通知模块 ✅
- **功能**：WebSocket实时推送、消息列表、已读标记
- **事件类型**：`NEW_BORROW_APPLY`、`REQUEST_APPROVED`、`RETURN_REQUESTED`等
- **定时任务**：每天早上9点执行逾期提醒

#### 7. 评价系统 ✅
- **功能**：借阅完成后双向评价、评分、评价标签
- **类型**：物品评价 + 用户评价

#### 8. 管理员后台 ✅
- **功能**：用户管理、物品审核、借阅管理、押金纠纷处理、举报审核、公告管理、敏感词管理
- **权限**：`ADMIN`角色可访问

### 四、数据库设计

**核心表结构**（共约15张表）：

| 表名 | 说明 | 关键字段 |
|------|------|---------|
| `users` | 用户表 | phone, credit_score, status, role |
| `items` | 物品表 | status, price_per_day, deposit, version |
| `borrows` | 借阅记录表 | status, start_date, end_date |
| `payments` | 支付记录表 | out_trade_no, status, total_amount |
| `messages` | 消息表 | type, is_read, related_id |
| `reviews` | 评价表 | rating, type, content |
| `posts` | 帖子表 | type, status, view_count, like_count |
| `comments` | 评论表 | parent_id（支持嵌套回复） |
| `audit_logs` | 审核日志表 | review_type, audit_result, reporter_id |

**数据库版本管理**：Flyway迁移脚本从 `V1` 到 `V15`，记录完整的结构变更历史。

### 五、关键技术方案

#### 1. 分页模块
- **后端**：`PageResponse<T>` 统一响应格式，基于Spring Data JPA `Page`
- **前端**：`usePagination` Hook（支持append/replace两种模式）+ `Pagination.vue` 组件
- **无限滚动**：`vInfiniteScroll` 指令

#### 2. 审核与举报系统重构（最新）
- **设计**：统一使用 `audit_logs` 表，通过 `review_type` 区分自动审核/用户举报
- **状态流转**：
  - 发帖 → 敏感词检测 → 通过(保存) / 拦截(记录日志,不保存)
  - 举报 → 创建记录(PENDING) → 管理员处理(RESOLVED/REJECTED)

#### 3. 接口规范
- **数组字段**：前端发送JSON字符串，后端存储为TEXT，返回时解析为List
- **图片路径**：存储相对路径（如 `items/uuid.jpg`），后端统一处理完整URL
