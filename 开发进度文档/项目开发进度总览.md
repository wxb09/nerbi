## 一、项目概述

邻里共享平台是一个社区物品共享系统，用户可以发布物品供他人借用，实现社区内的资源共享和循环利用。

### 核心功能

- 用户认证（手机号验证码登录 / 密码登录）
- 物品发布与管理
- 借阅申请与审批
- 实时消息通知（WebSocket）
- 管理员后台
- 评价系统

## 六、状态流转

### 物品状态

```
DRAFT → PENDING_REVIEW → AVAILABLE → BORROWED → AVAILABLE
                              ↓
                           OFFLINE
```

| 状态 | 说明 |
|-----|------|
| DRAFT | 草稿 |
| PENDING_REVIEW | 待审核 |
| AVAILABLE | 可借 |
| BORROWED | 借出中 |
| OFFLINE | 已下架 |

### 借阅状态

```
PENDING → APPROVED → ACTIVE → RETURN_REQUESTED → RETURNED
    ↓         ↓
REJECTED  CANCELLED
                ↓
             OVERDUE
```

| 状态 | 说明 |
|-----|------|
| PENDING | 待审批 |
| APPROVED | 已同意 |
| ACTIVE | 借用中 |
| RETURN_REQUESTED | 申请归还 |
| RETURNED | 已归还 |
| REJECTED | 已拒绝 |
| CANCELLED | 已取消 |
| OVERDUE | 已逾期 |

## 八、WebSocket 实时推送

### 连接地址

```
ws://localhost:8080/ws/message?token={jwt}
```

### 事件类型

| 事件 | 推送给 | 说明 |
|-----|-------|------|
| NEW_BORROW_APPLY | 物品所有者 | 新借阅申请 |
| REQUEST_APPROVED | 借用者 | 申请已通过 |
| REQUEST_REJECTED | 借用者 | 申请已拒绝 |
| RETURN_REQUESTED | 物品所有者 | 申请归还 |
| BORROW_RETURNED | 借用者 | 归还已确认 |

### 前端使用

```typescript
import { wsManager } from '../utils/websocket'

// 监听消息
wsManager.on('NEW_BORROW_APPLY', (message) => {
  // 处理消息
})
```
