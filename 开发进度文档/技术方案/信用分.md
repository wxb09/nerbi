## 二、信用分模型设计

### 2.1 评分维度体系

采用**五维信用模型**，总分100分：

```
┌─────────────────────────────────────────────────────────┐
│                    信用分构成 (100分)                      │
├─────────────┬─────────────┬─────────────────────────────┤
│   维度      │   权重      │         说明                │
├─────────────┼─────────────┼─────────────────────────────┤
│ 基础信用    │    20%      │ 实名认证、完善资料           │
│ 履约记录    │    30%      │ 借阅按时归还、无违约         │
│ 评价反馈    │    30%      │ 双向评价星级、标签           │
│ 社区贡献    │    10%      │ 发帖、分享、帮助邻居         │
│ 活跃程度    │    10%      │ 登录频率、使用时长           │
└─────────────┴─────────────┴─────────────────────────────┘
```

### 2.2 各维度详细计分规则

#### 维度1：基础信用（20分）

| 项目 | 分值 | 说明 |
|------|------|------|
| 手机号认证 | +5 | 注册即完成 |
| 地址认证 | +5 | `address_verify_status = VERIFIED` |
| 完善个人资料 | +5 | 头像+昵称+简介+楼栋 |
| 绑定支付宝 | +5 | `alipay_account` 不为空 |

#### 维度2：履约记录（30分）- 核心维度

**借阅履约率计算**：
```
履约率 = 成功完成的借阅数 / 总借阅数（借入+借出）

评分规则：
- 履约率 100%：30分
- 履约率 90%-99%：25分
- 履约率 80%-89%：20分
- 履约率 70%-79%：15分
- 履约率 60%-69%：10分
- 履约率 < 60%：5分

违约扣分项：
- 逾期未归还：-5分/次
- 物品损坏未赔偿：-10分/次
- 无故取消借阅：-3分/次
```

#### 维度3：评价反馈（30分）- 核心维度

**作为借入者评价（15分）**：
```
平均分 = 所有"我借入"的评价星级平均

评分规则：
- 平均4.5-5.0星：15分
- 平均4.0-4.4星：12分
- 平均3.5-3.9星：9分
- 平均3.0-3.4星：6分
- 平均< 3.0星：3分

加分项：
- 收到"守时归还"标签：+2分
- 收到"爱护物品"标签：+2分
- 收到"沟通顺畅"标签：+1分
```

**作为借出者评价（15分）**：
```
平均分 = 所有"我借出"的评价星级平均

评分规则：同上

加分项：
- 收到"物品完好"标签：+2分
- 收到"描述准确"标签：+2分
- 收到"响应及时"标签：+1分
```

#### 维度4：社区贡献（10分）

| 项目 | 分值 | 上限 |
|------|------|------|
| 发布有效帖子 | +0.5分/篇 | 5分 |
| 获得点赞 | +0.1分/个 | 2分 |
| 发布物品被借阅 | +1分/次 | 3分 |

#### 维度5：活跃程度（10分）

| 项目 | 分值 |
|------|------|

## 三、评分算法公式

### 3.1 核心算法

```java
public class CreditScoreCalculator {
    
    /**
     * 计算用户信用分
     * @param user 用户
     * @param borrowStats 借阅统计
     * @param reviewStats 评价统计
     * @param communityStats 社区贡献统计
     * @return 0-100的信用分
     */
    public int calculate(User user, BorrowStats borrowStats, 
                        ReviewStats reviewStats, CommunityStats communityStats) {
        
        // 基础信用分 (0-20)
        int baseScore = calculateBaseScore(user);
        
        // 履约记录分 (0-30)
        int performanceScore = calculatePerformanceScore(borrowStats);
        
        // 评价反馈分 (0-30)
        int reviewScore = calculateReviewScore(reviewStats);
        
        // 社区贡献分 (0-10)
        int contributionScore = calculateContributionScore(communityStats);
        
        // 活跃程度分 (0-10)
        int activeScore = calculateActiveScore(user);
        
        // 总分
        int totalScore = baseScore + performanceScore + reviewScore 
                       + contributionScore + activeScore;
        
        // 确保在0-100范围内
        return Math.max(0, Math.min(100, totalScore));
    }
}
```

### 3.2 时间衰减因子

引入**时间衰减**，近期行为权重更高：

```java
/**
 * 时间衰减权重
 * 近30天：权重1.0
 * 31-90天：权重0.8
 * 91-180天：权重0.6
 * 181-365天：权重0.4
 * 超过365天：权重0.2
 */
public double getTimeDecayWeight(LocalDateTime eventTime) {
    long days = ChronoUnit.DAYS.between(eventTime, LocalDateTime.now());
    
    if (days <= 30) return 1.0;
    if (days <= 90) return 0.8;
    if (days <= 180) return 0.6;
    if (days <= 365) return 0.4;
    return 0.2;
}
```

## 五、更新触发机制

### 5.1 触发时机

| 触发场景 | 触发动作 | 实时性 |
|---------|---------|--------|
| 用户完成地址认证 | 重新计算基础信用分 | 实时 |
| 借阅状态变为 RETURNED | 更新履约记录，重算信用分 | 实时 |
| 用户收到评价 | 更新评价统计，重算信用分 | 实时 |
| 用户发布帖子 | 更新社区贡献分（异步） | 延迟 |
| 每日凌晨 | 批量更新活跃程度分 | 定时任务 |

### 5.2 异步更新实现

```java
@Service
public class CreditScoreService {
    
    @Autowired
    private CreditScoreCalculator calculator;
    
    @Autowired
    private CreditScoreLogRepository logRepository;
    
    /**
     * 异步更新信用分
     */
    @Async
    public void updateCreditScoreAsync(Long userId, String changeType, 
                                       String reason, Long relatedId) {
        // 1. 获取用户当前分数
        User user = userRepository.findById(userId).orElseThrow();
        int oldScore = user.getCreditScore().intValue();
        
        // 2. 统计各维度数据
        BorrowStats borrowStats = borrowRepository.getStats(userId);
        ReviewStats reviewStats = reviewRepository.getStats(userId);
        CommunityStats communityStats = communityRepository.getStats(userId);
        
        // 3. 计算新分数
        int newScore = calculator.calculate(user, borrowStats, reviewStats, communityStats);
        
        // 4. 更新用户表
        user.setCreditScore(BigDecimal.valueOf(newScore));
        userRepository.save(user);
        
        // 5. 记录变更日志
        CreditScoreLog log = new CreditScoreLog();
        log.setUserId(userId);
        log.setOldScore(oldScore);
        log.setNewScore(newScore);
        log.setChangeValue(newScore - oldScore);
        log.setChangeType(changeType);
        log.setReason(reason);
        log.setRelatedId(relatedId);
        logRepository.save(log);
    }
}
```

### 5.3 事件监听触发

```java
@Component
public class CreditScoreEventListener {
    
    @Autowired
    private CreditScoreService creditScoreService;
    
    /**
     * 监听借阅完成事件
     */
    @EventListener
    public void onBorrowCompleted(BorrowCompletedEvent event) {
        // 更新借入者信用分
        creditScoreService.updateCreditScoreAsync(
            event.getBorrowerId(),
            "BORROW_COMPLETED",
            "借阅按时完成",
            event.getBorrowId()
        );
        
        // 更新借出者信用分
        creditScoreService.updateCreditScoreAsync(
            event.getLenderId(),
            "LEND_COMPLETED",
            "借出顺利完成",
            event.getBorrowId()
        );
    }
    
    /**
     * 监听评价创建事件
     */
    @EventListener
    public void onReviewCreated(ReviewCreatedEvent event) {
        creditScoreService.updateCreditScoreAsync(
            event.getToUserId(),
            "REVIEW_RECEIVED",
            "收到新评价",
            event.getReviewId()
        );
    }
}
```

  return Math.ceil(props.score / 20)
