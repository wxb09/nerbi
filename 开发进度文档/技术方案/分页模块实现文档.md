## 三、后端实现

### 3.1 PageResponse DTO

**文件位置**: `backend/demo/src/main/java/com/neighbor/common/dto/PageResponse.java`

```java
package com.neighbor.common.dto;

import org.springframework.data.domain.Page;
import java.util.List;

public record PageResponse<T>(
    List<T> content,       // 数据列表
    int number,            // 当前页码（0-based）
    int size,              // 每页条数
    int totalPages,        // 总页数
    long totalElements,    // 总记录数
    boolean first,         // 是否第一页
    boolean last,          // 是否最后一页
    boolean hasNext,       // 是否有下一页
    boolean hasPrevious    // 是否有上一页
) {
    public static <T> PageResponse<T> from(Page<T> page) {
        return new PageResponse<>(
            page.getContent(),
            page.getNumber(),
            page.getSize(),
            page.getTotalPages(),
            page.getTotalElements(),
            page.isFirst(),
            page.isLast(),
            page.hasNext(),
            page.hasPrevious()
        );
    }
}
```

**关键点**：
- `number` 使用 Spring Data JPA 的 **0-based** 页码
- 提供静态方法 `from(Page<T>)` 便捷转换

### 3.2 Controller 使用示例

```java
@GetMapping
public ApiResponse<PageResponse<PostListDTO>> getPosts(
        @RequestParam(defaultValue = "0") int page,
        @RequestParam(defaultValue = "10") int size) {
    Pageable pageable = PageRequest.of(page, size);
    Page<PostListDTO> pageResult = postService.getPosts(pageable);
    return ApiResponse.ok(PageResponse.from(pageResult));
}
```

## 四、前端实现

### 4.1 usePagination Hook

**文件位置**: `frontend/src/composables/usePagination.ts`

#### 功能特性

| 特性 | 说明 |
|------|------|
| 自动防抖 | 防止快速点击导致重复请求 |
| 状态管理 | 自动管理 loading/error/hasMore |
| 类型安全 | 泛型支持，类型推断 |
| 双模式 | `append`（加载更多）/ `replace`（覆盖） |
| 响应式参数 | 支持 computed params 响应式更新 |

#### API 定义

```typescript
export interface PageResponse<T> {
  content: T[]
  number: number        // 当前页（0-based）
  size: number          // 每页条数
  totalPages: number    // 总页数
  totalElements: number // 总记录数
  first: boolean
  last: boolean
  hasNext: boolean
  hasPrevious: boolean
}

export interface UsePaginationOptions<T> {
  pageSize?: number      // 默认 10
  mode?: 'append' | 'replace'  // 默认 replace
  params?: Ref<Record<string, any>>  // 响应式参数
}

function usePagination<T>(
  fetchFn: (page: number, size: number, params?: Record<string, any>) => Promise<any>,
  options?: UsePaginationOptions<T>
): {
  loading: Ref<boolean>
  error: Ref<string>
  data: Ref<T[]>
  page: ComputedRef<number>    // 当前页（0-based，用于显示）
  totalPages: Ref<number>
  totalElements: Ref<number>
  hasMore: ComputedRef<boolean>
  isEmpty: ComputedRef<boolean>
  loadMore: () => Promise<void>
  refresh: () => Promise<void>
  goToPage: (page: number) => Promise<void>
}
```

#### 使用示例

**模式一：加载更多（Append Mode）**

适用于论坛帖子、动态列表等场景：

```vue
<script setup>
import { usePagination } from '@/composables/usePagination'
import { forumApi } from '@/api/forum'

const activeTab = ref('latest')

// 响应式参数
const params = computed(() => ({
  sort: activeTab.value
}))

const {
  loading,
  error,
  data: posts,
  hasMore,
  loadMore,
  refresh
} = usePagination(
  (page, size, p) => forumApi.getPosts({ ...p, page, size }),
  { pageSize: 10, mode: 'append', params }
)

// 切换筛选条件时自动刷新
watch(activeTab, () => refresh())
</script>

<template>
  <PostCard v-for="post in posts" :key="post.id" :post="post" />
  <button v-if="hasMore" @click="loadMore">加载更多</button>
</template>
```

**模式二：分页模式（Replace Mode）**

适用于管理后台列表：

```vue
<script setup>
import { usePagination } from '@/composables/usePagination'
import Pagination from '@/components/common/Pagination.vue'
import { auditApi } from '@/api/audit'

const keyword = ref('')
const category = ref('')

const params = computed(() => ({
  keyword: keyword.value || undefined,
  category: category.value || undefined
}))

const {
  loading,
  error,
  data: words,
  page,
  totalPages,
  totalElements,
  refresh,
  goToPage
} = usePagination(
  (page, size, p) => auditApi.getWords({ ...p, page, size }),
  { pageSize: 10, mode: 'replace' }
)

// 监听筛选条件变化
watch([keyword, category], () => refresh())
</script>

<template>
  <table>
    <tr v-for="word in words" :key="word.id">
      <td>{{ word.word }}</td>
    </tr>
  </table>
  <Pagination
    v-if="totalPages > 1"
    :page="page"
    :total-pages="totalPages"
    :total-elements="totalElements"
    @change="goToPage"
  />
</template>
```

### 4.2 Pagination 组件

**文件位置**: `frontend/src/components/common/Pagination.vue`

#### 功能特性

| 特性 | 说明 |
|------|------|
| 智能页码 | ≤7 页显示全部，>7 页智能省略 |
| 总记录数 | 显示 "共 X 条记录" |
| 状态显示 | 当前页 / 总页数 |
| 禁用状态 | 首页禁用"上一页"，末页禁用"下一页" |
| 响应式 | 适配移动端 |

#### Props

```typescript
interface Props {
  page: number       // 当前页（0-based）
  totalPages: number // 总页数
  totalElements: number  // 总记录数
}
```

#### Events

```typescript
interface Emits {
  (e: 'change', page: number): void  // 页码变化
}
```

#### 使用示例

```vue
<script setup>
const page = ref(0)
const totalPages = ref(5)
const totalElements = ref(50)

function handlePageChange(newPage: number) {
  page.value = newPage
  loadData(newPage)
}
</script>

<template>
  <Pagination
    :page="page"
    :total-pages="totalPages"
    :total-elements="totalElements"
    @change="handlePageChange"
  />
</template>
```

**页面效果**：

```
共 50 条记录，第 1 / 5 页
[上一页] [1] [2] [3] [4] [5] [下一页]
```

## 六、注意事项

### 6.1 页码约定

- **后端**: 0-based（Spring Data JPA 默认）
- **前端显示**: 0-based（已统一）
- **用户可见**: 建议转换为 1-based（如 "第 1 页"）

### 6.2 常见问题

| 问题 | 原因 | 解决方案 |
|------|------|----------|
| 分页显示在第 2 页 | `page.value++` 导致多 1 | 使用 `computed(() => Math.max(0, page.value - 1))` |
| 筛选条件变化不刷新 | 未监听 params 变化 | 使用 `watch` 监听并调用 `refresh()` |
| 快速点击重复请求 | 未防抖 | `usePagination` 已内置防抖 |

### 6.3 后端返回格式兼容性

`PageResponse` 字段与 Spring Data JPA `Page` 对应关系：

| PageResponse 字段 | Page 方法 | 说明 |
|-------------------|-----------|------|
| content | getContent() | 数据列表 |
| number | getNumber() | 当前页码（0-based） |
| size | getSize() | 每页条数 |
| totalPages | getTotalPages() | 总页数 |
| totalElements | getTotalElements() | 总记录数 |
| first | isFirst() | 是否第一页 |
| last | isLast() | 是否最后一页 |
| hasNext | hasNext() | 是否有下一页 |
| hasPrevious | hasPrevious() | 是否有上一页 |
