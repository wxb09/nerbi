## 图片路径问题修复完成

### 问题分析

后端返回的图片路径有两种格式：
1. **用户头像**：`/uploads/avatars/user1.webp`（带 `/uploads/` 前缀）
2. **物品图片**：`items/uuid.webp`（不带 `/uploads/` 前缀）

### 修复方案

修改 `getImageUrl` 函数，根据路径格式智能处理：

```typescript
const getImageUrl = (path: string | undefined) => {
  if (!path) return '默认头像 URL'
  if (path.startsWith('http')) {
    return path
  }
  // 如果路径已经是 /uploads/ 开头，直接返回
  if (path.startsWith('/uploads/')) {
    return path
  }
  // 否则添加 /uploads/ 前缀（物品图片的情况）
  return `/uploads/${path}`
}
```
