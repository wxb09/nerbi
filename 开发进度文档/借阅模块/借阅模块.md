### 借阅流程

```
1. 借阅人提交申请 → POST /api/borrows → 状态: 
PENDING
2. 物品主人审批 → POST /api/borrows/{id}/
approve → 状态: APPROVED 或 REJECTED
3. 借阅人确认取货 → POST /api/borrows/{id}/
pickup → 状态: ACTIVE
4. 物品主人确认归还 → POST /api/borrows/{id}/
return → 状态: RETURNED
```
