## 一、本期完成（2026-04-22 ~ 04-23）

### 1. 审核与举报系统重构

| 改动 | 说明 |
|------|------|
| 删除冗余字段 | posts/comments 表移除 `audit_status`、`audit_reason` |
| 扩展 audit_logs | 新增 `review_type`、`reporter_id`、`handler_id`、`reason`、`result` |
| 统一审核记录 | 自动审核 + 用户举报 + 管理员处理 共用一张表 |

**状态流转**：
```
发帖 → 敏感词检测 → 通过(保存) / 拦截(记录日志,不保存)
举报 → 创建记录(PENDING) → 管理员处理(RESOLVED/REJECTED)
```

### 2. 帖子举报功能

- 帖子卡片"更多"按钮（底部操作栏）
- 自己的帖子：删除
- 他人的帖子：举报（填写原因）
- 点击外部自动关闭菜单

### 3. 管理员举报审核

- 表格布局展示举报列表
- 查看详情弹窗（显示举报原因、帖子内容、处理信息）
- 处理操作：删除内容 / 驳回举报

### 4. 公告管理

- 论坛侧边栏接入后端公告数据
- 点击公告查看详情
- 管理员后台"论坛管理"可增删改查公告
