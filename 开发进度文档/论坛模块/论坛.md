### 二、功能模块设计

#### 2.1 帖子管理模块

| 功能 | API | 方法 | 说明 |
|-----|-----|------|------|
| 帖子列表 | `/api/posts` | GET | 分页、按类型/社区筛选、最新/最热排序 |
| 帖子详情 | `/api/posts/{id}` | GET | 包含作者信息、评论数、点赞数 |
| 发布帖子 | `/api/posts` | POST | 支持图片上传、标签 |
| 编辑帖子 | `/api/posts/{id}` | PUT | 仅作者可编辑 |
| 删除帖子 | `/api/posts/{id}` | DELETE | 软删除，仅作者可删除 |
| 热门帖子 | `/api/posts/hot` | GET | 按点赞数+评论数排序 |

#### 2.2 评论系统模块

| 功能 | API | 方法 | 说明 |
|-----|-----|------|------|
| 评论列表 | `/api/posts/{postId}/comments` | GET | 分页，支持嵌套回复 |
| 发表评论 | `/api/posts/{postId}/comments` | POST | 支持回复（parent_id） |
| 删除评论 | `/api/comments/{id}` | DELETE | 仅评论者可删除 |

#### 2.3 点赞功能模块

| 功能 | API | 方法 | 说明 |
|-----|-----|------|------|
| 点赞 | `/api/likes` | POST | 支持帖子/评论 |
| 取消点赞 | `/api/likes` | DELETE | 按目标类型和ID |
| 检查点赞状态 | `/api/likes/check` | GET | 当前用户是否已点赞 |

#### 2.4 社区公告模块

| 功能 | API | 方法 | 说明 |
|-----|-----|------|------|
| 公告列表 | `/api/announcements` | GET | 按社区筛选 |
| 公告详情 | `/api/announcements/{id}` | GET | - |

### 三、后端开发计划

#### 3.1 需要创建的文件

```
backend/demo/src/main/java/com/neighbor/
├── controller/api/
│   ├── PostController.java          # 帖子控制器
│   ├── CommentController.java       # 评论控制器
│   └── LikeController.java          # 点赞控制器
├── service/
│   ├── PostService.java             # 帖子服务接口
│   ├── CommentService.java          # 评论服务接口
│   ├── LikeService.java             # 点赞服务接口
│   └── impl/
│       ├── PostServiceImpl.java     # 帖子服务实现
│       ├── CommentServiceImpl.java  # 评论服务实现
│       └── LikeServiceImpl.java     # 点赞服务实现
├── dto/
│   ├── PostListDTO.java             # 帖子列表DTO
│   ├── PostDetailDTO.java           # 帖子详情DTO
│   ├── CreatePostDTO.java           # 创建帖子DTO
│   ├── CommentDTO.java              # 评论DTO
│   └── LikeDTO.java                 # 点赞DTO
├── entity/
│   └── Like.java                    # 点赞实体（需确认是否存在）
└── repository/
    └── LikeRepository.java          # 点赞仓储
```

#### 3.2 关键业务逻辑

**帖子发布流程：**
```
1. 验证用户登录状态
2. 校验内容（标题、内容长度）
3. 处理图片上传（复用现有UploadService）
4. 设置帖子类型、社区ID
5. 保存帖子
6. 返回帖子详情
```

**评论嵌套设计：**
```
评论表通过 parent_id 实现树形结构
- 一级评论：parent_id = null
- 二级评论：parent_id = 一级评论ID
- 前端展示：一级评论 + 其下所有回复
```

**点赞去重：**
```
使用 likes 表的 UNIQUE KEY (user_id, target_type, target_id)
防止重复点赞
```

### 七、技术要点

#### 7.1 遵循现有代码规范

- Controller 使用 `ApiResponse<T>` 统一返回格式
- 使用 `Authentication` 获取当前用户
- DTO 与 Entity 分离
- Repository 使用 Spring Data JPA

#### 7.2 安全考虑

- 帖子/评论内容需做 XSS 过滤
- 删除操作需验证权限（仅作者可删除）
- 点赞需防重复

#### 7.3 性能优化

- 帖子列表使用分页查询
- 评论使用懒加载（展开时加载回复）
- 点赞数使用缓存（可选）
