> 最后更新：2026-04-20

## 一、模块概述

论坛模块是邻里共享平台的社区交流功能，用户可以发布帖子、评论互动、点赞等，实现社区内的情感联结和信息分享。

### 核心功能

- 帖子发布与管理（支持多种类型）
- 评论系统（支持嵌套回复）
- 点赞功能（帖子/评论）
- 帖子列表（最新/最热排序、类型筛选）

## 五、关键实现细节

### 5.1 懒加载问题处理

Post 实体的 `user` 和 `community` 关联使用 `FetchType.LAZY`，通过 `@EntityGraph` 预加载：

```java
@EntityGraph(attributePaths = {"user", "community"})
Page<Post> findByStatus(String status, Pageable pageable);
```

### 5.2 点赞 Toggle 模式

一个接口完成点赞/取消，前端无需判断状态：

```java
public LikeStatusDTO toggleLike(LikeRequest request, Long userId) {
    boolean exists = likeRepository.existsByUserIdAndTargetTypeAndTargetId(...);
    if (exists) {
        // 取消点赞
        likeRepository.deleteByUserIdAndTargetTypeAndTargetId(...);
        updateTargetLikeCount(..., -1);
        return new LikeStatusDTO(false, count);
    } else {
        // 添加点赞
        likeRepository.save(new Like(...));
        updateTargetLikeCount(..., 1);
        return new LikeStatusDTO(true, count);
    }
}
```

### 5.3 评论计数同步

评论增删时同步更新帖子的 `commentCount`：

```java
// 创建评论
post.setCommentCount(post.getCommentCount() + 1);
postRepository.save(post);

// 删除评论
post.setCommentCount(Math.max(0, post.getCommentCount() - 1));
postRepository.save(post);
```

### 5.4 浏览量统计

帖子详情接口自动增加浏览量：

```java
public PostDetailDTO getPostById(Long id, Long currentUserId) {
    Post post = postRepository.findByIdWithFetch(id);
    post.setViewCount(post.getViewCount() + 1);
    postRepository.save(post);
    return toDetailDTO(post, currentUserId);
}
```
