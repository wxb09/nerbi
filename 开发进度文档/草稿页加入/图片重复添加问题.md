## 🐛 问题原因

**原因1：JPA 实体缺少 `orphanRemoval`**
```java
// 修改前：clear() 只在内存中清空列表，数据库记录不会被删除
@OneToMany(mappedBy = "item", cascade = CascadeType.ALL, fetch = FetchType.LAZY)
```

**原因2：空列表逻辑错误**
```java
// 修改前：空列表时不会进入 if 块，导致图片无法清空
if (imageUrls != null && !imageUrls.isEmpty()) {
    item.getImages().clear();  // 永远不会执行
}
```

---

## ✅ 修复内容

### 1. [Item.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/entity/Item.java#L80)
```java
@OneToMany(mappedBy = "item", cascade = CascadeType.ALL, orphanRemoval = true, fetch = FetchType.LAZY)
```
添加 `orphanRemoval = true`，当图片从列表中移除时，JPA 会自动删除数据库中的孤儿记录。

### 2. [ItemServiceImpl.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/service/impl/ItemServiceImpl.java#L220-L233)
```java
if (data.containsKey("images")) {
    List<String> imageUrls = (List<String>) data.get("images");
    item.getImages().clear();  // 移到外层，始终执行
    if (imageUrls != null && !imageUrls.isEmpty()) {
        // 添加新图片...
    }
}
```
将 `clear()` 移到外层，确保空列表时也能清空原有图片。
