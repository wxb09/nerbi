## 🐛 问题原因

**后端 `populateItemFromData` 方法没有处理 `status` 字段**

当前端传递 `status: 'AVAILABLE'` 时，后端不会更新物品状态。

---

## ✅ 修复内容

### 1. [ItemServiceImpl.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/service/impl/ItemServiceImpl.java#L214-L224)

添加 `status` 字段处理：
```java
if (data.containsKey("status")) {
    try {
        ItemStatus status = ItemStatus.valueOf((String) data.get("status"));
        item.setStatus(status);
        if (status == ItemStatus.AVAILABLE && item.getPublishedAt() == null) {
            item.setPublishedAt(LocalDateTime.now());
        }
    } catch (IllegalArgumentException ignored) {
    }
}
```

### 2. [ProfileView.vue](file:///d:/ai练/fast/frontend/src/views/ProfileView.vue#L661-L668)

简化上架逻辑：
```typescript
if (isOffline) {
  await itemApi.updateItem(item.id, { status: 'AVAILABLE' })
  alert('物品已上架')
}
```
