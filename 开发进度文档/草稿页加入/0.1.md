## 📊 完整交互流程

```
用户进入发布/编辑页面
    ↓
判断路由参数
├─ /publish (新建)
│   └─ 空白表单
│
├─ /publish/:id (编辑)
│   └─ 加载物品详情
│       └─ 按钮："保存修改"
│
└─ /draft/:id (草稿)
    └─ 加载草稿数据
        └─ 按钮："发布物品"
            ↓
用户填写表单
    ↓
点击"保存草稿" → 保存到后端 → 提示成功
    ↓
点击"发布物品/保存修改" → 提交 → 跳转到物品详情
```
