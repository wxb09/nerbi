## 🔍 现有实时通信架构分析

### 📡 后端 WebSocket 实现

**核心组件**：

1. **[WebSocketConfig.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/websocket/WebSocketConfig.java)**
   - 端点：`/ws/message`
   - 通过 URL 参数传递 token 进行认证
   - 允许跨域访问

2. **[WebSocketAuthInterceptor.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/websocket/WebSocketAuthInterceptor.java)**
   - 握手拦截器
   - 从 URL 参数提取 token 并验证 JWT
   - 将 userId 存入 WebSocketSession 属性中

3. **[WebSocketMessageHandler.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/websocket/WebSocketMessageHandler.java)**
   - 核心消息处理器
   - 维护用户会话映射：`Map<Long, WebSocketSession>`
   - 功能：
     - ✅ 单点推送：`sendMessageToUser(userId, message)`
     - ✅ 广播推送：`broadcastToAll(message)`
     - ✅ 用户在线状态：`isUserOnline(userId)`
     - ✅ 在线人数统计：`getOnlineCount()`
   - 支持心跳检测（PING/PONG）

4. **[WebSocketPushService.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/websocket/WebSocketPushService.java)**
   - 推送服务封装
   - 消息类型：
     - `NEW_MESSAGE` - 新消息通知
     - `UNREAD_COUNT` - 未读数更新
     - `NOTIFICATION` - 系统通知

### 💬 现有消息系统

**消息类型** ([MessageType.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/enums/MessageType.java))：
```java
SYSTEM          // 系统通知
BORROW_APPLY    // 借阅申请
BORROW_APPROVED // 借阅已同意
BORROW_REJECTED // 借阅已拒绝
RETURN_DUE      // 归还提醒
RETURN_OVERDUE  // 超期提醒
RETURN_CONFIRM  // 归还确认
```

**消息实体** ([Message.java](file:///d:/ai练/fast/backend/demo/src/main/java/com/neighbor/entity/Message.java))：
- `from_user_id` - 发送者（可为空，系统消息）
- `to_user_id` - 接收者
- `type` - 消息类型
- `title` - 标题
- `content` - 内容
- `related_id` - 关联ID（如借阅ID）
- `is_read` - 已读状态
- `created_at` - 创建时间

**消息流程**：
```
创建消息 → 保存数据库 → WebSocket推送 → 更新未读数
```
