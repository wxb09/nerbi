## 二、统一错误处理方案

### 方案1：增强全局异常处理器

**当前代码**：
```java
@ExceptionHandler(Exception.class)
public ApiResponse<Void> handleUnknown(Exception ex) {
    return ApiResponse.fail(5000, "系统异常");
}
```

**优化后**：
```java
@Slf4j
@RestControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(BusinessException.class)
    public ApiResponse<Void> handleBusiness(BusinessException ex) {
        log.warn("[业务异常] code={}, message={}", ex.getCode(), ex.getMessage());
        return ApiResponse.fail(ex.getCode(), ex.getMessage());
    }

    @ExceptionHandler(MethodArgumentNotValidException.class)
    public ApiResponse<Void> handleMethodArgumentNotValid(MethodArgumentNotValidException ex) {
        List<String> errors = ex.getBindingResult().getFieldErrors().stream()
            .map(error -> error.getField() + ": " + error.getDefaultMessage())
            .collect(Collectors.toList());
        String msg = String.join(", ", errors);
        log.warn("[参数校验失败] {}", msg);
        return ApiResponse.fail(2001, msg);
    }

    @ExceptionHandler(Exception.class)
    public ApiResponse<Void> handleUnknown(Exception ex) {
        log.error("[系统异常]", ex);  // 记录完整堆栈
        return ApiResponse.fail(5000, "系统繁忙，请稍后重试");
    }
}
```

**收益**：
- 生产环境可通过日志追踪错误
- 用户看到友好提示，不暴露内部细节

### 方案2：引入断言工具类

**当前代码**（每个Service都写）：
```java
Item item = itemRepository.findById(id)
    .orElseThrow(() -> new BusinessException(ErrorCode.ITEM_NOT_FOUND));

if (!item.getOwner().getId().equals(userId)) {
    throw new BusinessException(ErrorCode.NOT_YOUR_ITEM);
}
```

**优化后**（使用断言工具）：
```java
// AssertUtils.java
public class AssertUtils {
    public static void notNull(Object obj, ErrorCode errorCode) {
        if (obj == null) {
            throw new BusinessException(errorCode);
        }
    }
    
    public static void isTrue(boolean condition, ErrorCode errorCode) {
        if (!condition) {
            throw new BusinessException(errorCode);
        }
    }
    
    public static void equals(Object a, Object b, ErrorCode errorCode) {
        if (!Objects.equals(a, b)) {
            throw new BusinessException(errorCode);
        }
    }
}
```

**使用示例**：
```java
Item item = itemRepository.findById(id).orElse(null);
AssertUtils.notNull(item, ErrorCode.ITEM_NOT_FOUND);
AssertUtils.equals(item.getOwner().getId(), userId, ErrorCode.NOT_YOUR_ITEM);
```

**收益**：
- 代码更简洁
- 减少重复代码
- 统一异常抛出方式

### 方案3：空指针防护

**当前风险代码**：
```java
List<Item> similarItems = itemRepository.findSimilarItems(
    item.getCategory().getId(),  // 如果category为null，NPE！
    ItemStatus.AVAILABLE,
    itemId,
    limit
);
```

**优化方案**：
```java
// 方案A：Optional链式调用
Long categoryId = Optional.ofNullable(item.getCategory())
    .map(Category::getId)
    .orElseThrow(() -> new BusinessException(ErrorCode.CATEGORY_NOT_FOUND));

// 方案B：使用工具类
Long categoryId = OptionalUtils.mapOrThrow(
    item.getCategory(), 
    Category::getId, 
    ErrorCode.CATEGORY_NOT_FOUND
);
```

### 1. Service层单元测试

**测试目标**：`ItemServiceImpl`

```java
@ExtendWith(MockitoExtension.class)
class ItemServiceImplTest {

    @Mock
    private ItemRepository itemRepository;
    
    @Mock
    private UserRepository userRepository;
    
    @InjectMocks
    private ItemServiceImpl itemService;

    @Test
    @DisplayName("根据ID查询物品 - 存在")
    void getItemById_Exists() {
        // Given
        Long itemId = 1L;
        Item item = new Item();
        item.setId(itemId);
        item.setName("电钻");
        when(itemRepository.findById(itemId)).thenReturn(Optional.of(item));
        
        // When
        ItemDetailDTO result = itemService.getItemById(itemId);
        
        // Then
        assertThat(result.getName()).isEqualTo("电钻");
        verify(itemRepository).save(any()); // 验证浏览量+1
    }

    @Test
    @DisplayName("根据ID查询物品 - 不存在")
    void getItemById_NotFound() {
        // Given
        Long itemId = 999L;
        when(itemRepository.findById(itemId)).thenReturn(Optional.empty());
        
        // When & Then
        assertThatThrownBy(() -> itemService.getItemById(itemId))
            .isInstanceOf(BusinessException.class)
            .hasFieldOrPropertyWithValue("code", 3001);
    }

    @Test
    @DisplayName("更新物品 - 无权操作")
    void updateItem_NoPermission() {
        // Given
        Long itemId = 1L;
        Long ownerId = 1L;
        Long otherUserId = 2L;
        
        Item item = new Item();
        User owner = new User();
        owner.setId(ownerId);
        item.setOwner(owner);
        
        when(itemRepository.findById(itemId)).thenReturn(Optional.of(item));
        
        // When & Then
        assertThatThrownBy(() -> itemService.updateItem(itemId, Map.of(), otherUserId))
            .isInstanceOf(BusinessException.class)
            .hasFieldOrPropertyWithValue("code", 4009);
    }
}
```
